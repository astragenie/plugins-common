  (non-`EEXIST`, e.g. `EACCES`) that used to `throw err` at line 63 now

  `transient: true`).

  "put with invalid trial data never throws, returns err(DeterministicError)"

  existing tests to the `Result`-wrapped API; added

  non-`EEXIST` error).
- `packages/gepa-core/CHANGELOG.md` — `0.8.0` entry documenting the
  breaking-but-0.x return-type change and the bounded blast radius (no other
