## Lessons

- The correctness reviewer caught a real resource leak (shared-AbortSignal listener accumulation in `withTimeoutSignal`) that BOTH the builder's green run and the parallel TS reviewer missed — it was pre-existing in gepa-core's original `linkSignal` but the extraction centralized + broadened it to gemini/ollama. Adversarial "does it leak under a shared signal?" review beats happy-path suites for shared/frozen utils.
- Fixing the leak before freezing the API (rather than deferring) was the right call: gepa-core's sequential-runner passes ONE signal across a whole GEPA run — the leak would grow with judge-call count in exactly the long-loop workload this package serves.
- Consistency matters on a frozen surface: http.ts initially exposed only via `./http` subpath while jsonl.ts was dual-exposed (root + subpath). Aligned to root re-export.

## Surprises

- gemini/ollama previously IGNORED an external abort signal entirely; the migration made them honor it (a latent correctness improvement), but no provider-level test covers that behavior change — flagged as a follow-up.

## Followups

- Add provider-level tests for the gemini/ollama "now honors external signal" behavior change (currently only the CHANGELOG documents it).
- Consolidation opportunity: all 5 providers still hand-roll `res.ok` + raw error + `(await res.json()) as T` instead of the new `fetchJson<T>` generic (pre-existing, not introduced here).
- FEAT-008 (infra-error policy reconciliation) still pending triage.

## What went well

Clean multi-consumer migration (5 providers), real bug fixed pre-freeze, no scope leak (astramem half correctly deferred per §8.2), 212 gepa-core tests stayed green, memory now on for continuity.

## What went wrong

Builder's self-verify green missed a resource leak in the new frozen API — happy-path coverage doesn't exercise shared-signal reuse.

## What I would do differently next time

For any new shared util that takes an AbortSignal/handle, require a "reuse across N calls, assert no listener/timer accumulation" test in the builder's own gate, not just at review.
