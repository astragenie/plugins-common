## Lessons

- Reviewers catch real gaps the builder's own green run misses: `rotate()`'s primary size>maxBytes branch had zero coverage despite all tests passing. Frozen-for-migration APIs need branch coverage, not just happy-path — added via test-automator top-up (13→15 tests).

- `readSafe` torn-line counting is position-agnostic (mid-file corruption counted same as torn final line, no line number) — acceptable now, flagged for a diagnostics follow-up since the module is shared/frozen.

## Surprises

- The jsonl error policy now DIVERGES from SLICE-01's lock manager: jsonl.ts throws for infra failures (matches result.ts's "infra errors still throw"), but SLICE-01's file-lock-manager returns `err(TransientError)` for the same fs-failure class. Both APIs are declared frozen — the inconsistency is baked in unless reconciled.

## Followups

- FILE a decision FEAT: reconcile the infra-error policy across plugin-std consumers (throw vs `err(TransientError)`) before more repos adopt either frozen API.
- `file-store.ts` cleanup: mixes sync fs (`existsSync`/`mkdirSync`/`writeFileSync`) with async jsonl helpers; `jsonlPathFor`'s `mkdirSync` is redundant (append() already mkdirs). Non-blocking.
- Doc note: `TrialStore.put()`'s `Promise<Result<...>>` can still reject if `append()` throws TransientError — JSDoc should say so.
- `rotate()` default-archive-path (Date.now naming) + rename-failure throw path still untested.
- `tail()` is O(file-size) — possible bounded-read follow-up if a large-file consumer needs it.

## What went well

Clean first-consumer migration: gepa-core's silent-drop guarded-read (the M2 defect) deleted and replaced with the shared `readSafe` that counts torn lines. All gates green, crash-safety preserved (append still single-syscall), 210 gepa-core tests unchanged.

## What went wrong

Builder reported "11 tests" vs actual 12/13; minor. Rotate coverage gap slipped the builder's self-verify — caught at review.

## What I would do differently next time

Have the builder assert branch coverage on any API declared "frozen at extraction" before returning, not just a passing suite.
